Smart Building Energy Consumption Prediction using MATLAB  
(Machine Learning – 5 Models + App Designer UI)

This project predicts **smart building energy consumption** using multiple machine learning models in **MATLAB**, and provides a clean and interactive UI built using **App Designer**.

🔍 Project Overview
The goal of this project is to accurately predict energy usage in a smart building based on input parameters like:
- Temperature  
- Humidity  
- Light intensity  
- CO₂ level  
- Occupancy  

The project includes:

✔ Data preprocessing  
✔ Training 5 different ML models  
✔ Model comparison  
✔ A complete App Designer UI for user-friendly predictions  

---

## 🤖 Machine Learning Models Used
1. **Linear Regression**  
2. **Decision Tree Regression**  
3. **Support Vector Regression (SVR)**  
4. **K-Nearest Neighbors (KNN)**  
5. **Random Forest Regression**

A performance comparison table is included in the screenshots.

---

## 🧪 Dataset
The dataset used is:  
📄 `smart_building.csv`

It includes:
- Temperature  
- Humidity  
- Light  
- CO2  
- Occupancy  
- Energy consumption (target variable)

## 🖥 MATLAB App Designer UI
The App allows users to:
- Input temperature, humidity, light, CO2  
- Select any of the trained ML models  
- Get predicted energy consumption instantly  
- View UI components clearly
